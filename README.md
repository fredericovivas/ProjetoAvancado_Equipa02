# ProjetoAvancado_Equipa02

## Componentes
| Pasta | Conteúdo |
|---|---|
| `web/` | Aplicação web de administração |
| `api/` | API central e regras de negócio |
| `mobile/` | Aplicação móvel para participantes (Flutter/Dart) |
| `infrastructure/` | Ambiente de execução, configuração e procedimentos |
| `tests/` | Testes e evidências |
| `docs/` | Documentação técnica |
| `presentation/` | Apresentação final |
